# 英検3級 語彙学習

- `eiken3-vocab.xlsx`：単語・日本語訳、習得状況、復習日、進捗集計。
- `index.html`：検索、覚えた語の非表示、日本語訳を隠す練習、バックアップ移行。

収録：1,209項目。3級PDFは全1210語の表記に対し、実際の掲載番号は1～1209です。

## 使い方

HTMLをダウンロードしブラウザで開いてください。GitHub Pagesで公開する場合はmainブランチのルートを指定してください。記録はブラウザ内に保存され、Excelとは自動同期しません。級ごとに記録を分離しています。

## 出典

ユーザー提供の英検3級ポスターPDF（英語漬け.com／えいぷら表記）。掲載順・日本語訳を基本に転記し、PDFの文字分割と明らかな抽出上の乱れを補正しました。例文・優先度は原資料にないためExcelでは空欄です。元資料の権利は各権利者に帰属します。
